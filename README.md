# 말랑 옷장 🐚

해달·물범·북극여우·웜벳·골든햄스터에게 옷을 입히고, 캐릭터가 직접 점수를 매기는 픽셀 옷입히기 게임이에요.
빌드 과정이 필요 없는 정적 사이트라서 Vercel 에 그대로 올리면 돼요.

## 파일 구조
모든 파일이 저장소 맨 위에 함께 있어요.
```
index.html      화면 뼈대 (모든 화면이 여기 있어요)
style.css       디자인 (아래쪽 "픽셀 테마", "레드카펫 패션쇼" 부분)
data.js         캐릭터·옷 53종 데이터, 색채 조화 점수 공식
pixel.js        캐릭터와 옷을 도트로 그리는 코드
icons.js        티켓·조개·하트 같은 도트 아이콘
scene.js        바닷가 도트 배경
save.js         저장/불러오기 (LocalStorage), 레벨·경험치
app.js          화면 이동, 옷장, 평가, 상점, 소리·일본어 음성
dodge.js        미니게임 1: 돌 피하기
rhythm.js       미니게임 2: 파도 리듬 (Q W E Space, 노래 3곡)
cast.js         패션쇼 경쟁자 9명 · 심사위원 4명 그림
show.js         레드카펫 패션쇼 (스테이지 1: 강원 감자골 패션쇼)
main.js         게임 시작
Galmuri11*.woff2  도트 글꼴 (라이선스: Galmuri-OFL.txt)
```

## 업데이트할 때
- `index.html` 안의 `?v=6` 숫자를 하나 올리면 방문자 브라우저가 새 파일을 바로 받아요.
- 저장 이름(`mallang-closet-save-v2`)과 옷 ID(`h_ribbon` 같은 것)는 바꾸지 마세요. 기존 기록을 못 찾게 돼요.

## Vercel 에 올리는 방법

### 방법 1. GitHub 로 올리기 (추천)
1. GitHub 에 새 저장소를 만들고 이 폴더 안의 파일을 전부 올려요. (`index.html` 이 저장소 맨 위에 있어야 해요)
2. https://vercel.com 에 로그인 → **Add New… → Project** → 방금 만든 저장소 **Import**
3. 설정 화면에서
   - Framework Preset: **Other**
   - Build Command: 비워 두기
   - Output Directory: 비워 두기
4. **Deploy** 를 누르면 끝. 이후 GitHub 에 올릴 때마다 자동으로 다시 배포돼요.

### 방법 2. Vercel CLI 로 올리기
```bash
npm i -g vercel
cd mallang-closet
vercel          # 처음 한 번: 질문에 엔터로 답하면 미리보기 주소가 나와요
vercel --prod   # 실제 주소로 배포
```

## 내 컴퓨터에서 실행해 보기
`index.html` 을 바로 열어도 게임은 돌아가지만, 브라우저 보안 때문에 도트 글꼴이 안 보일 수 있어요.
간단한 서버로 열면 배포한 것과 똑같이 보여요.
```bash
npx serve .              # 또는: python3 -m http.server 8000
```

## 저장 방식
- 진행 상황(조개, 티켓, 해금한 옷, 코디, 레벨·경험치, 미니게임 기록)은 브라우저의 **LocalStorage** 에
  `mallang-closet-save-v2` 라는 이름으로 저장돼요.
- 바뀔 때마다 바로 저장하고, 탭을 닫거나 다른 앱으로 넘어갈 때 한 번 더 저장해요. 새로고침해도 그대로예요.
- 예전 버전 저장(`mallang-closet-v1`)이 있으면 처음 열 때 자동으로 옮겨 와요.
- 저장은 **사이트 주소마다 따로**예요. 미리보기 주소와 실제 주소, 다른 브라우저, 시크릿 창은 기록을 공유하지 않아요.
- 상점 맨 아래 **지금 저장** 버튼으로 바로 저장하고, **처음부터 다시 하기** 로 기록을 지울 수 있어요.

## 게임 규칙 요약
- 처음엔 모자·상의·하의·신발이 2개씩만 열려 있고, 가방은 잠겨 있어요.
- 평가 1번에 코디 티켓 1장. 처음 10장, 5분마다 1장 자동 충전(자동 충전은 10장까지).
- 점수 = 색 조화(Ou & Luo 2색 조화 모델) + 캐릭터 취향 + 코디 밸런스 → 점수만큼 조개 보상.
- 레벨이 오를 때마다 티켓 +1.
- 돌 피하기: 캐릭터마다 하루 1번(다섯 친구라 하루 최대 5번). 캐릭터별로 속도·생명력이 달라요.
- 파도 리듬: 횟수 제한 없음. 노래 3곡 중 하나가 무작위로 나오고, 점수가 오를수록 BPM·노트가 빨라져요. 점수 목표를 **처음** 넘길 때만 티켓 +1.
- 레드카펫 패션쇼: 참가비 티켓 2장. 참가자 10명(나 + 경쟁자 9명), 내 순서는 무작위. 내 차례에 좌클릭/우클릭(← →)으로 균형잡기.
  심사위원 4명이 0~10점씩, 합계로 순위. 1등이면 스테이지 2(전국 패션 위크) 초대장 — 스테이지 2는 아직 개발 중.
  심사 점수 = 캐릭터와 코디가 잘 맞는 정도 55% + 옷의 고급스러움 45% + 심사위원 취향 + 균형잡기(조금).
